The dataset in /data/MERVJP/varssim_nocal/* includes the daily timeseries of the observed precipitation, temperature, pet and streamflow of each catchment, along with the output of the uncalibrated MARRMoT model. 

# Observed values 
The observed values are from the following database. The calibrated MARRMoT model outputs are also availble here. 
Sawada, Y. and Okugawa, S.: Multi-model Ensemble for Robust Verification of hydrological modeling in Japan (MERV-Jp) (2.0), https://doi.org/10.5281/zenodo.8176305, 2023.

# Uncalibrated model outputs
ver1_1 includes the output of the uncalibrated MARRMOT model v1.4. Models with unstable outputs have been excluded. 
- Knoben, W. J. M.: wknoben/MARRMoT: MARRMoT_v1.3, , https://doi.org/10.5281/zenodo.3552961, 2019.
ver2_0 includes the output of the uncalibrated MARRMoT model v2.1.2. All 47 models availble have been included.
- Trotter, L., Knoben, W. J. M., Fowler, K. J. A., Saft, M., and Peel, M. C.: Modular Assessment of Rainfall–Runoff Models Toolbox (MARRMoT) v2.1: an object-oriented implementation of 47 established hydrological models for improved speed and readability, Geoscientific Model Development, 15, 6359–6369, https://doi.org/10.5194/gmd-15-6359-2022, 2022.
